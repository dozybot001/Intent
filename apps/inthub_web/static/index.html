IntHub is a project continuity workspace for developers and Agents. It brings together Intent goals, Snap checkpoints and durable Decisions so work can resume with its context intact.

Sync semantic history from the Intent CLI, review the current continuation brief, explore the timeline and search project history. Explicitly published projects can also be shared in a read-only showcase.

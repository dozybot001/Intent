# Intent 7.6.7

Released 2026-10-31. IntHub's showcase now follows the language of the page. The CLI did not change.

- **Showcase language.** Switching the page between English and Chinese moves to the matching version of the showcase, on the same tab.
- **Showcase picker.** The project switcher on a showcase page offers both versions, and picking one sets the page's language too.
- **Backups.** Copies taken before a release now expire after 90 days, as the privacy notice says.

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.7"`.

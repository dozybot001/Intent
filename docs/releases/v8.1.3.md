# Intent 8.1.3

Released 2026-11-02.

- **IntHub's one-line definition.** IntHub now describes itself the same way everywhere: "A cloud platform for Intent hosting and collaborative development" (云端的 Intent 托管与协作开发平台). This covers the sign-in page, the About dialog, the page title, the link preview and the IntHub guide.
- **The browser tab follows the language.** The tab title on the sign-in page now appears in Chinese when the page does.
- **The sign-in page opens at the top on phones.** It no longer scrolls past the introduction to reach the first sign-in button.

Run `pipx upgrade intent-history`, or re-run the installer.

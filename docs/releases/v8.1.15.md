# Intent CLI 8.1.15

Released 2026-11-06.

- **Safer Tenon sign-in during the move to tenonai.cn.** IntHub sends its client secret and tokens only to addresses under the Tenon issuer it discovered, and never follows a redirect to another one. Nothing changes in the CLI.
- IntHub's server again runs on Python 3.9 with older Authlib releases.

Run `pipx upgrade intent-history`, or re-run the installer.

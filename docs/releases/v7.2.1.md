# Intent 7.2.1

Released 2026-10-30. Fixes from a walkthrough of a new user's first hour, and an IntHub layout audit.

## First run

- `itt init` picks the agent you use. It takes the agent running the command, or else the only agent installed (`~/.codex` or `~/.claude`). If neither settles it, it asks at a terminal; `--host` still overrides. `itt maintenance on/off/status` default to the host the project is configured for.
- `itt init` prints its next steps in plain words: trust the hooks, work as usual, and how to resume. Before, it referred to an internal field. It also keeps the project's hook file out of Git in this clone, like `.intent/`.
- The recommended Skill install is now `npx skills add dozybot001/Intent -g -a claude-code -a codex`. The previous `--all` created about 50 agent folders in the home directory.
- `itt push` and `itt auth login` without a valid token now return `AUTH_REQUIRED` and say how to sign in, instead of "status 401". Other server errors show the server's own message.
- `itt status` suggests `itt auth login` and `itt push` to back the history up on IntHub. `itt hub start` says where it runs and how to publish to it.
- The terminal no longer shows "No active decisions to attach" and similar notes as warnings. Agents still receive them in JSON.

## IntHub

- The setup guide adds the Skill install step. On inthub.tenon.asia it signs in with plain `itt auth login` and pushes with plain `itt push`; linking a different project name is optional. It ends with how to resume later.
- The copy button on command snippets sat on the snippet's top edge in empty states. It is now centred on the first line of every snippet.
- On phones, commands no longer break inside a flag (`--depends-` / `on`), filter menus stay on screen, and the toast and search messages size to their text.
- Long Decision titles and Intent titles in the filter menus end in an ellipsis instead of running past the card.
- The access-token dialog fits its content, and the token field shows the start of the token.
- The Timeline tab hides a zero count like the other tabs.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.2.1"`. Nothing in `.intent/` changes.

## Verification

- 511 tests pass locally on Python 3.14. The 4 PostgreSQL tests run in release qualification and in CI on Python 3.9, 3.13 and 3.14.
- A layout audit in headless Chrome covered 46 IntHub states at 1440, 1024, 768 and 390 px, in light and dark, English and Chinese. It checks for sideways scrolling, text cut without an ellipsis, controls crossing a border, IDs broken across lines, icon alignment and contrast. It found 63 problems before this release and none after.
- A new user's path was walked from a clean home directory: the installer on the system Python 3.9, the Skill install, `itt init` under Claude Code and Codex, signing in, and pushing to a hub.

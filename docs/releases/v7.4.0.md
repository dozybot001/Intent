# Intent 7.4.0

Released 2026-10-30. Every object now says who recorded it, every push says who pushed it, and IntHub shows what each push changed.

## Identity

- New Intents, Snaps and Decisions record `author`, read the way Git reads its identity: `ITT_AUTHOR_NAME` and `ITT_AUTHOR_EMAIL`, then `GIT_AUTHOR_NAME` and `GIT_AUTHOR_EMAIL`, then `user.name` and `user.email`. With Git configured there is nothing to set up. `origin` still names the agent.
- Without an identity, recording continues and the field is left out. `itt init`, `itt status` and `itt doctor` warn. Objects from before this release keep their shape.
- A Snap recorded in a Git repository stores its commit, and marks uncommitted changes to tracked files as `dirty`.
- `itt push` declares the pusher, and sends the `origin` remote as a link when it is on github.com, gitlab.com or gitee.com. Credentials in the remote URL are never sent.

## IntHub

- **History tab.** Every push is a revision. The list shows what it added and changed, who pushed it and when, grouped by day.
- **Revision details.** A revision lists the objects it added, status changes with their reasons, and relations added or withdrawn, like a commit page.
- **Authors.** Timeline entries, the brief, lists and sheets show "Ana Lee · Claude Code". The timeline can be filtered by author as well as by Intent, and both filters are kept in the URL.
- **Verified.** An object pushed by the account that owns its author's email is marked Verified. IntHub now keeps the verified email from Tenon sign-in for this, so the mark starts after your next sign-in.
- **Commits.** A Snap's sheet shows its commit and links to it on GitHub, GitLab or Gitee.
- **Settings.** Your profile shows which Git email links Snaps to your account.
- **Sign-in.** The sign-in gate lists GitHub, Apple and email instead of one Tenon button, and each goes straight to that method. A first sign-in creates a Tenon Account.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.4.0"`. Older clients keep working: they ignore `author` and `git`, and keep them when they change an object. The IntHub database gains schema v6, which is additive.

## Verification

- 557 tests pass locally on Python 3.14 with PostgreSQL 16. CI runs them on Python 3.9, 3.13 and 3.14.
- The web tests cover the history, revision and author views with a stubbed API. End-to-end flows ran in headless Chrome against real hubs seeded through the CLI with three authors and 43 pushes: paging, deep links, filters, commit links and Verified marks.
- The layout audit ran 38 states at 1440, 1024, 768 and 390 px in light and dark, English and Chinese, and found no problems.

# Intent 7.6.3

Released 2026-10-31. An internal restructuring with no change in behaviour: the largest source files are split by job, and the test suite is smaller.

## Development

- **Web app.** `app.js` (6,300 lines) and `styles.css` (5,500 lines) became 38 scripts and 25 stylesheets, loaded in order, with no build step. Asset URLs now carry the running release, so nobody bumps a revision by hand.
- **API server.** One 870-line closure became three classes for transport, identity and routes. The database module has separate connection, schema and migration files.
- **CLI.** The store, the commands and the text rendering are split by job. Every name the store exposed still works.
- **Tests.** The web logic tests and the CLI tests have one file per area, and 35 web tests that only pinned source text are gone.
- **Structure health score:** 61 before, 88 now.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.3"`.

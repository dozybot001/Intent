# Intent CLI 8.2.2

Released 2026-11-14.

- **Projects linked before 8.2.0 work again.** A project whose remote was saved under IntHub's old name, inthub.tenon.asia, stopped `itt status`, `push`, `pull` and `fetch` with REMOTE_CHANGED after 8.2.0. The old name now reads as the same hub at inthub.tenonai.cn, so the project, its revision and your saved token carry over, and the next push or pull saves the new name. Nothing to relink.

Run `pipx upgrade intent-history`, or re-run the installer.

# Intent 7.5.1

Released 2026-10-31. IntHub's header now separates preferences, settings and the account, and every option reads as an icon and a label.

## IntHub

- **Three entries in the header.** Preferences (sliders) holds appearance, language, refresh and about, and works without signing in. Settings (gear) opens a page with access tokens and teams. Account (avatar) holds your profile, the Tenon account center and sign out.
- **New addresses.** Tokens and teams moved to `/settings` and `/settings/teams`, and deleting the account moved to `/account/danger`. `/account/tokens` and `/account/teams`, added in 7.5.0, are gone.
- **Icons and labels.** Menu items, tabs, section navigation, buttons and filters all have an icon and a label, including the email sign-in option, which had none. A button keeps its icon while it is busy.
- **Section navigation.** Items no longer sit almost on top of each other.
- **Focus rings.** Clicking no longer leaves a white ring around a control. Keyboard users still get one.
- **Confirmation dialogs.** The bottom edge of the text field is no longer cut off.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.5.1"`. The CLI and the database are unchanged.

## Verification

- 578 tests pass locally on Python 3.14 with PostgreSQL 16. CI runs them on Python 3.9, 3.13 and 3.14.
- The layout audit ran 264 page states at 12 widths from 1440 to 320 px, in English and Chinese, and found no problems.
- A scan of every page, menu and dialog found no action left as text alone. Headless Chrome ran the token, invite, rename, visibility, transfer and language flows against a hosted-mode hub with only the sign-in stubbed.

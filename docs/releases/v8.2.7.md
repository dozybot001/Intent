# Intent CLI 8.2.7

Released 2026-11-18.

- **Repository files for readers, contributors and security reports.** The Chinese README is now `README.zh-CN.md`, and both READMEs end with the publisher, Tenon AI, linked to the Intent CLI product page. `CHANGELOG.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1) and `SECURITY.md` are at the repository root. Report a security problem to support@tenonai.cn or through GitHub's private reporting; `SECURITY.md` also describes how `.intent/`, access tokens, IntHub Local and the hosted IntHub are protected. Bug reports and feature requests use forms in English and Chinese, and release notes come in both languages from this version on. Nothing changes in the CLI or IntHub.

Run `pipx upgrade intent-history`, or re-run the installer.

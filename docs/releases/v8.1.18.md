# Intent CLI 8.1.18

Released 2026-11-10.

- **IntHub's link preview shows the IntHub mark.** The share image used to be a screenshot of the sign-in page, so chat apps that crop previews to a square showed a sliver of the page with the mark cut off. It is now the IntHub mark centred on white, so a square crop keeps the whole mark. Nothing changes in the CLI.

Run `pipx upgrade intent-history`, or re-run the installer.

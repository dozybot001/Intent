# Intent 7.6.5

Released 2026-10-31. The IntHub Flow page has a new layout. Nothing else changed.

- **Trees, not a staircase.** Columns no longer follow creation time, which left long empty stretches. Each group of related Intents is a tree read left to right, and groups pack across the page, open work first. Each card shows its creation time instead.
- **One trunk, one join.** A parent reaches its kids through one trunk, and its ended parts come back to one point. Before, every part had its own curve and its own loop back.
- **Lines run forward.** An Intent that depends on or conflicts with another sits to its right, so these lines no longer double back across the graph.
- **Smaller details.** The legend lists only what the graph shows, the graph follows the window width, and a line of text no longer starts with punctuation. The Project band ends in a `+N` count when it runs out of room.

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.5"`.

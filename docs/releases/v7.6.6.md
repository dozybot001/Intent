# Intent 7.6.6

Released 2026-10-31. This release gets Intent ready for a wider audience. The CLI did not change.

- **Showcase.** IntHub links to Intent's own history, in English and Chinese, at `inthub.tenon.asia/showcase`. It needs no sign-in. The showcase is a curated copy with the original dates and relations.
- **Privacy notice.** IntHub has its own notice at `inthub.tenon.asia/privacy`.
- **README.** Rewritten around the moment a new session resumes the work, with a demo built from real sessions.
- **Docs.** The vision, Flow, teams and continuation case docs are rewritten for readers outside the project, and internal planning docs are gone.
- **Installing from mainland China.** The installers accept `INTENT_REPO`, and the Chinese README installs from Gitee.
- **Service.** Hosted data is backed up daily to a second provider, the restore has been tested, and an outside probe watches the service, disk and backups.

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.6"`.

# Intent CLI 8.2.11

Released 2026-11-20.

- **Removed: IntHub's old address no longer serves the API.** `inthub.tenon.asia` answers 410 for every API call and moves every page to `inthub.tenonai.cn`. Intent CLI 8.2.0 and later already use the new address. On an older CLI, upgrade and sign in again.
- **Changed: sign in again once if you signed in before 8.2.0.** Tokens saved under the old address are no longer read, so `itt` asks you to run `itt auth login`. A project remote or global setting saved under the old address still reads as the new one, and the next push or pull saves it.
- **Removed: the placeholders for retired IntHub features.** The GitHub sign-in and public-profile routes, retired earlier, now get an ordinary 404 instead of a 410.
- **Removed: installing releases before 7.1.** The installers install `intent-history` only, and no longer look for or remove an `intent-cli` install from Intent 7.0.
- **Changed: the docs describe the product as it is.** [Semantic Git](https://github.com/dozybot001/Intent/blob/main/docs/EN/semantic-git.md) now explains how revisions, branches, merges and sync work, without the plan it was written from. The internal dogfooding protocol left the public docs.

Run `pipx upgrade intent-history`, or re-run the installer.

## 中文

2026-11-20 发布。

- **移除：IntHub 旧地址不再提供接口。** `inthub.tenon.asia` 对所有接口请求返回 410，所有页面跳转到 `inthub.tenonai.cn`。Intent CLI 8.2.0 及以后的版本本来就用新地址；更早的版本请升级后重新登录。
- **变更：8.2.0 之前登录过的，需要重新登录一次。** 不再读取保存在旧地址下的令牌，`itt` 会提示运行 `itt auth login`。项目远端或全局设置里保存的旧地址仍按新地址读取，下一次 push 或 pull 时改存为新地址。
- **移除：IntHub 已下线功能的占位。** 早先下线的 GitHub 登录和公开主页路由，现在和其他不存在的地址一样返回 404，不再返回 410。
- **移除：安装 7.1 之前的版本。** 安装脚本只安装 `intent-history`，也不再查找和卸载 Intent 7.0 留下的 `intent-cli`。
- **变更：文档只写产品现在的样子。** [语义版 Git](https://github.com/dozybot001/Intent/blob/main/docs/CN/semantic-git.md) 改为说明修订、分支、合并和同步如何工作，去掉了当初的实施计划。内部的自用测试协议移出了公开文档。

运行 `pipx upgrade intent-history`，或重新运行安装脚本。

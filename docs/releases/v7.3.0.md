# Intent 7.3.0

Released 2026-10-30. IntHub gets settings: manage your access tokens, and rename, export or delete a project. Clones follow a rename.

## IntHub

- **Account settings.** The account menu now opens a Settings page with your Tenon profile, access tokens and account deletion.
- **Access tokens.** Give a token a name and a 30-, 90- or 365-day expiry. The list shows when each token was created, last used and expires, and any token can be revoked. Before, tokens could be created but not listed or revoked in the browser.
- **Project settings.** A new Settings tab renames a project, downloads an export (the current semantic snapshot and its revision chain) or deletes the project once you type its name. Deleting removes only the copy on IntHub; local `.intent` directories are untouched.
- Renaming and deleting are browser actions. Access tokens cannot do either.
- Text fields use a soft focus ring. The white outline on the access-token field in dark mode is gone, and the dialog now opens with focus on Copy token.
- The gear menu for appearance and language is now labelled Preferences, so it no longer shares a name with Settings.

## CLI

- `itt status`, `itt push` and `itt pull` follow a project renamed on IntHub. They look the project up by its ID, print "Renamed on IntHub: old → new", and `push` and `pull` store the new name. itt 7.2 and earlier look projects up by name and report `REMOTE_CHANGED` until upgraded.
- A project deleted on IntHub reports `REMOTE_CHANGED` instead of being recreated silently, and suggests `itt hub link` followed by `itt push` to publish the history again. Local history is untouched.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.3.0"`. The IntHub database needs no migration, and nothing in `.intent/` changes.

## Verification

- 522 tests pass locally on Python 3.14, and the 5 PostgreSQL tests pass on PostgreSQL 16. CI runs them on Python 3.9, 3.13 and 3.14.
- The web tests cover the settings pages with a stubbed API. Eight flows were run in headless Chrome against real hubs (IntHub Local and a Tenon account): export, rename, delete, generating and revoking a token, and back and forward on `/settings`.
- The layout audit ran 30 states at 1440, 1024, 768 and 390 px in light and dark, English and Chinese, and found no problems.

# Intent CLI 8.2.15

Released 2026-11-20.

- **Changed: IntHub stores Tenon identities under `account.tenonai.cn`.** Accounts, sign-in sessions and deletion records were keyed by the account service's old issuer. A database migration copies each account's identity to the current issuer and moves sessions and deletion records with it, so every account keeps its projects and everyone stays signed in. The old identity rows stay for one release, in case it has to be rolled back, and the next release removes them.

The CLI did not change. Run `pipx upgrade intent-history`, or re-run the installer.

## 中文

2026-11-20 发布。

- **变更：IntHub 改用 `account.tenonai.cn` 保存 Tenon 身份。** 账号、登录会话和删除记录原来都以账号服务的旧签发方为键。一次数据库迁移把每个账号的身份复制到当前签发方，会话和删除记录也一并改过去，所有账号的项目都还在，已登录的也不用重新登录。旧的身份记录再保留一个版本，以备回滚，下一个版本删除。

# Intent CLI 8.2.9

Released 2026-11-19.

- **The company's English name drops the city.** `LICENSE`, both READMEs, the package metadata, the Claude Code plugin marketplace and IntHub's privacy policy now name Tenon Artificial Intelligence Technology Co., Ltd. The legal texts add the Chinese registered name, 长沙榫卯人工智能科技有限公司, in brackets. The privacy policy changes only in the name and keeps its effective date, November 13, 2026.
- **A shorter README.** It leads with one demo, Quick start and eight one-line features. The comparison with AGENTS.md and agent memory moved to [Vision](https://github.com/dozybot001/Intent/blob/main/docs/EN/vision.md), IntHub's getting-started steps to the [IntHub guide](https://github.com/dozybot001/Intent/blob/main/docs/EN/inthub-collaboration.md), and uninstalling, now with Windows, pipx and uv, to the [CLI reference](https://github.com/dozybot001/Intent/blob/main/docs/EN/cli.md#uninstall). Nothing changes in the CLI.

Run `pipx upgrade intent-history`, or re-run the installer.

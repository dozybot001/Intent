# Intent CLI 8.2.0

Released 2026-11-13.

- **IntHub is now at inthub.tenonai.cn.** The CLI talks to the new address. Remotes, settings and sign-ins saved under inthub.tenon.asia keep working: the CLI reads them as the new address and never contacts the old one, so nobody signs in again. Every request names the CLI and its version, as `User-Agent: intent-cli/8.2.0`.
- **inthub.tenon.asia forwards to the new address.** Its pages and browser sign-in open on inthub.tenonai.cn. Older CLIs can still push, pull and sign in through the old address for now, but it will stop serving them later, so upgrade soon.
- The privacy notice, the account and legal links, and the share preview use the new addresses.

Run `pipx upgrade intent-history`, or re-run the installer.

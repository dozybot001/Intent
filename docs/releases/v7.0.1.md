# Intent 7.0.1

Released 2026-10-05. IntHub sign-in lifetime update.

- IntHub remembers both ordinary users and Tenon administrators for 30 days after successful sign-in. The persistent cookie and server session use the same deadline.
- OIDC tokens remain fully verified during sign-in. Their shorter lifetime does not shorten the independent product session; routine requests do not extend it or contact Tenon.
- The previous runtime session-duration override is retired. Existing sessions keep their original deadline; independent sign-out and local identity checks remain in place.
- Authorization attempts and CLI access-token lifetimes remain unchanged.

Production uses the existing exact-commit release gates and reversible deployment. Targeted authentication, API, UI and deployment checks passed before release; the full local and server gates run during publication.

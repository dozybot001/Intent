# Intent CLI 8.2.13

Released 2026-11-20.

- **Removed: IntHub no longer answers at `inthub.tenon.asia`.** Its last site, which answered 410 and redirected pages, is gone, and so are the release and smoke steps for it. IntHub is only at `inthub.tenonai.cn`.
- **Removed: `itt` no longer rewrites the old address.** A project remote or global setting still saved as `https://inthub.tenon.asia` is used as written and no longer reaches IntHub. Run `itt remote add origin https://inthub.tenonai.cn` in that project, or `itt auth login --api-base-url https://inthub.tenonai.cn` for the global setting.
- **Changed: the privacy notice names only the current address.**

Run `pipx upgrade intent-history`, or re-run the installer.

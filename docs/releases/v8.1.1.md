# Intent 8.1.1

Released 2026-11-01. Everyday use, from a first-time reader's point of view.

- **Conflicts say what to decide.** A stopped merge names each object and field, gives the `itt resolve` command to run, and each step says what comes next. `itt status` stays accurate while a merge is open.
- **Remote branches are one word away.** `itt switch feature` starts from `origin/feature` when only the remote has it, and `itt switch -c NAME REV` starts anywhere. `itt pull` says what else arrived.
- **`itt status` counts revisions** ahead of and behind origin, and `itt log` shows which branches point where, like `git log --decorate`.
- **Agents know where they stand.** `itt inspect` and the hook context name the branch when it is not `main`, and any open merge. Refusals from IntHub keep their own code, such as `NON_FAST_FORWARD`, with the next step.
- **IntHub** lists branches beside `main` on the History tab, and a project's Settings give the `itt clone` command.
- **Clearer messages.** A mistyped command suggests the right one, a mistyped short ID reads as not found, and `itt branch -r`, `itt hub status` and `itt hub link` read as sentences. Flags have help text.
- **The Skill teaches every command**, and the docs no longer describe 7.x behaviour. Reinstall it with `npx skills add dozybot001/Intent -g -a claude-code -a codex -y` to get this: upgrading the CLI does not update the Skill.

Run `pipx upgrade intent-history`, or re-run the installer.

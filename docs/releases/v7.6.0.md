# Intent 7.6.0

Released 2026-10-31. `itt auth login` now happens in the browser, a diverged copy has a way back, and IntHub gains what a public service needs: quotas, rate limits, takedowns and a real front door.

## CLI

- **Browser sign-in.** `itt auth login` shows a code and waits, as `gh auth login` does. Approve it at `/device` from any device, so it works over SSH and in containers. The CLI collects a 90-day token named after the machine. `--token` and `INTHUB_TOKEN` still work, and older hubs fall back to a pasted token.
- **`itt pull --rebase`.** After parallel recording, the remote's objects stay as they are and local-only objects take the next free IDs, with their references. `--dry-run` shows the renumbering first. A status the two copies disagree on is reported, and a local close is kept.
- **No credential helper needed.** A machine without one keeps the token in a private file, as `gh` does.
- **Committed `.intent/`.** A clone no longer fails because Git dropped an empty folder.
- **Uninstall.** `itt maintenance off --remove-hooks` removes Intent's hooks, even after `.intent/` is gone. The README now covers removal.
- **Clearer status and errors.** `itt maintenance status` says whether the hooks were seen running and never prompts. Network errors name the cause and the next step. `itt hub start` explains a busy port. `itt help` works, and dry runs say which side is ahead.
- **Skill install.** The documented command adds `-y`; without a terminal it used to exit 0 and install nothing.

## IntHub

- **Settings dialog.** Settings and Account open in one fixed-size dialog over the current page, full screen on phones. Each section keeps its address, and Back closes it. Team pages and project settings stay pages.
- **No browser-styled controls.** Selects are listboxes of our own and hints use the page's popover. Toasts appear above dialogs.
- **Usage.** Settings → Usage shows each account's and team's allowance: 100 projects and 1 GB of history. An account can create 10 teams.
- **Check before publishing.** Making a project public scans it for keys and tokens and asks again if it finds any.
- **Front door.** The sign-in page says what IntHub is and how to start. Every page links the operator's terms, privacy policy, acceptable use, contact and filing number. Public projects have a report link. Unknown addresses return a real 404, and `robots.txt`, `security.txt` and share images exist.

## Operators

- **Rate limits** cover the whole API, and a limiter guards the Tenon deletion callback.
- **`python -m apps.inthub_api.admin`** finds accounts, suspends and restores them, and takes projects down or reinstates them. See the production guide.
- **Authlib 1.9.1** replaces 1.6.12, which had eight published vulnerabilities. The containers now have memory limits.
- Schema v8 is additive: device logins, `projects.stored_bytes`, and suspension columns.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.0"`.

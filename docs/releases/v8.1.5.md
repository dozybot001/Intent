# Intent 8.1.5

Released 2026-11-02.

- **Agents ask before a project goes unrecorded.** When development starts in a project without Intent, the agent asks once whether to turn on real-time recording. A no is remembered through the new `itt maintenance decline`, which writes nothing to the project.
- **Recording that is not running says so.** Until a project's hooks have run, `itt status` and `itt inspect` say nothing is being recorded automatically and name the step that fixes it.

Run `pipx upgrade intent-history`, or re-run the installer. This release changes the Skill too, so re-run the Skill install.

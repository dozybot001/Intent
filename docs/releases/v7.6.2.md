# Intent 7.6.2

Released 2026-10-31. The footer now sits at the bottom of the window on short pages, and releases take less time. The CLI is unchanged.

## IntHub

- **Footer.** It follows the content, as on most sites, and a short page pushes it to the bottom of the window instead of leaving it in the middle.

## Development

- **Tests run in parallel.** The full suite takes about 20 seconds instead of 140, and a release runs it once rather than again on the server Builder.
- **`python scripts/changed_tests.py`** runs only the tests a change can affect.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.2"`.

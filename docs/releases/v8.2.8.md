# Intent CLI 8.2.8

Released 2026-11-18.

- **The copyright holder is now the company.** `LICENSE`, the package metadata and the Claude Code plugin marketplace name Changsha Tenon Artificial Intelligence Technology Co., Ltd., and both READMEs gained Contributing and License sections that say so. The MIT terms are unchanged.
- **`SECURITY.md` follows Tenon AI's common template.** Report a security problem to support@tenonai.cn, which replies within one business day, or through GitHub's private reporting; fixes go into the latest release. The note on IntHub Local's trust boundary moved to [Teams and sharing](https://github.com/dozybot001/Intent/blob/main/docs/EN/inthub-collaboration.md). Nothing changes in the CLI or IntHub.

Run `pipx upgrade intent-history`, or re-run the installer.

# Intent CLI 8.1.16

Released 2026-11-07.

- **IntHub can retire CLI tokens issued before a given time.** Operators run `python -m apps.inthub_api.admin retire-tokens TIME`, with `--dry-run` to count first. It is for the day tenon.asia becomes a redirect: everyone signs in to the CLI once more, and web sessions, which last 30 days at most, need no step. Nothing changes in the CLI.

Run `pipx upgrade intent-history`, or re-run the installer.

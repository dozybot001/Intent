# Intent CLI 8.2.16

Released 2026-11-20.

- **Removed: IntHub's identity records under the old issuer.** 8.2.15 copied every Tenon identity to `account.tenonai.cn` and kept the old rows in case it had to be rolled back. It was accepted, so a database migration now deletes the old rows, after carrying over any written while the two releases overlapped. Nobody needs to sign in again.

The CLI did not change. Run `pipx upgrade intent-history`, or re-run the installer.

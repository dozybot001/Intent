# Intent 8.0.0

Released 2026-10-31. Intent's history now works like Git.

- **Revisions.** Every write records a revision, so there is nothing to commit. `itt log` lists them, `itt log --graph` draws branches and merges, and `itt log --snaps` keeps the old checkpoint list.
- **Semantic diff.** `itt show REV` and `itt diff A..B` report goals, checkpoints and decisions rather than lines of JSON.
- **Hash IDs.** New objects get IDs such as `snap-3f9a2c1d5e6b`, so copies recording in parallel cannot collide. Text shows seven digits, and any unique prefix works as an argument. Counter IDs stay valid.
- **Branches.** `itt branch` and `itt switch` work as in Git, and the working copy follows.
- **Git worktrees.** A linked worktree finds the project's history and records on its own branch, so agents working side by side no longer lose it. Push and pull run from the main worktree.
- **Semantic merge.** `itt merge` combines both sides and stops only when they set the same field differently. `itt status` lists the conflicts, `itt resolve` settles them, and `itt merge --continue` or `--abort` finishes.
- **IntHub.** Hash IDs are accepted and shown short.

Upgrading: an Intent 7 project stays readable, but writes stop until you run `itt migrate` once in it. Migration keeps every ID and object, writes a backup to `.intent/backups/`, takes `--force` for a damaged history, and cannot be undone by Intent 7. Push and pull work on `main`; pushing branches comes next.

Everyone sharing a project needs 8.x once it has hash IDs or merges, because 7.x cannot read them. Run `pipx upgrade intent-history`, or re-run the installer.

# Intent CLI 8.2.12

Released 2026-11-20.

- **Fixed: `itt push` no longer times out on a slow uplink.** Every request had 15 seconds in total, including the time to send its body, so the first push of a project with a few hundred Snaps and trees failed with `NETWORK_TIMEOUT` where uploads run at a few dozen KB/s. A request now gets 15 seconds plus one second for every 16 KB it sends, and a push uploads in batches of at most 1 MB instead of 6 MB, so each batch finishes in about a minute even then.

Run `pipx upgrade intent-history`, or re-run the installer.

## 中文

2026-11-20 发布。

- **修复：上行慢的网络里 `itt push` 不再超时。** 以前每个请求总共只有 15 秒，发送请求体的时间也算在内。在上传只有每秒几十 KB 的网络里，有几百个 Snap 和 tree 的项目第一次推送就会报 `NETWORK_TIMEOUT`。现在每个请求在 15 秒之外，每发送 16 KB 再多给 1 秒；推送按每批最多 1 MB 上传（原来是 6 MB），这样网速再慢，每批也能在一分钟左右传完。

运行 `pipx upgrade intent-history`，或重新运行安装脚本。

# Intent 8.1.0

Released 2026-11-01. Sync now works the way Git does.

- **Branches on IntHub.** `itt push` sends the current branch to the same branch on the remote, from any worktree. `itt push --delete BRANCH` removes one. `main` stays.
- **`itt pull` merges.** It fetches, then merges `origin/BRANCH` into this branch, stopping only where both sides set the same field differently. There is nothing to rebase any more, so `--rebase` only prints a note.
- **`itt fetch`** brings the remote's branches into `origin/*` without touching this branch. `itt branch -r` lists them, and `itt merge origin/feature` merges one.
- **`itt clone PROJECT`** sets Intent up in a project folder and brings its history and branches in one step. Only members can clone.
- **IntHub keeps the revision graph.** Pushes send only what the remote lacks. The history page shows every revision on `main`, with merges marked.

Upgrading: nothing to run. A project on IntHub moves to the graph the first time it is used. The first `itt push` from a copy that synced before 8.1 asks you to run `itt pull`, which joins the two histories, starting from the last push that copy saw. 8.0 and 7.x clients can keep reading and pushing `main` for now; what they push joins the graph, and branches are visible only from 8.1.

Run `pipx upgrade intent-history`, or re-run the installer.

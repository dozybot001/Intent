# Intent 7.0.0

Released 2026-10-05. Stable CLI and Skill release; no development suffix.

## Independent semantic history

- Intent history is independent of Git. Shared repositories and append-only semantic revisions replace the old workspace protocol; familiar remote, push and pull operations do not require changing Git remotes.
- Account-private IntHub histories use endpoint-scoped global authentication, with access tokens created on the IntHub website and entered privately into the CLI.
- Legacy workspace migration is complete for the maintained deployment. This major version removes the old workspace/link/sync protocol; integrations using it must upgrade to the shared-history commands. Export and retain independent backups before upgrading other installations with legacy data.

## Project-local real-time maintenance

- `itt init` enables continuous maintenance for a new history; existing projects use `itt maintenance on`. `off` affects only the selected project.
- Project-local `UserPromptSubmit` and `Stop` hooks supply opening context and bounded closure checks. After Agent configuration, desktop users review and trust both under **Settings → Hooks**; CLI users use `/hooks`.
- Closure can be recorded, no-op or failed. No new Snap is required for a quiet turn. Hook configuration and trust do not prove semantic quality; actual execution observations remain distinct.
- The Skill separates independent Intent goals and verified Snap milestones, supports safe argv transport, and guides missing-CLI installation after confirmation and optional website/token authentication.

## Reliability and deployment

- Structured JSON errors, tolerant corruption diagnostics, path containment, case-insensitive create protection, locked graph snapshots and bounded recent history.
- IntHub uses Tenon sign-in and the account-private shared-history model, with updated responsive browsing.
- Production remains exact-commit, immutable-bundle, reversible blue-green deployment; GitHub Actions and Pages are not deployment dependencies. Human versions use the stable tag; full SHA remains the audit identity.

## Install

Install the attached wheel in an isolated environment, or:

```text
pipx install "intent-cli @ git+https://github.com/dozybot001/Intent.git@v7.0.0"
```

For an existing pipx installation, use the approved upgrade/reinstall workflow. Verify `itt version` reports `7.0.0`. The attached Skill archive and Python distributions are built from the same fixed tag; local recording needs no IntHub account.

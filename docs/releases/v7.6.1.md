# Intent 7.6.1

Released 2026-10-31. This is the release that carries 7.6.0 to the hosted IntHub. The CLI and the web app are the same as in 7.6.0, whose notes list the changes.

## Release

- A test fixture looked like a private key, so the release gate stopped 7.6.0 before it reached production, and the gate hid its reason. The fixture no longer matches, the gate prints the reason, and the ordinary test suite now runs the same scan.

## Upgrading

Re-run the installer, or `pipx install --force "intent-history @ git+https://github.com/dozybot001/Intent.git@v7.6.1"`.

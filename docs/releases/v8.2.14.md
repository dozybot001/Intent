# Intent CLI 8.2.14

Released 2026-11-20.

- **Changed: IntHub reads the platform role from the account service's new claim name.** Tenon's account service now sends it as `https://tenonai.cn/claims/platform_role`, and IntHub switched in the same release window. The values are still `admin` and `user`. Sessions already signed in are not affected.

The CLI did not change. Run `pipx upgrade intent-history`, or re-run the installer.

## 中文

2026-11-20 发布。

- **变更：IntHub 按账号服务的新声明名读取平台角色。** Tenon 账号服务改为用 `https://tenonai.cn/claims/platform_role` 发送这个声明，IntHub 在同一个发布窗口切换。取值仍是 `admin` 和 `user`，已登录的会话不受影响。
